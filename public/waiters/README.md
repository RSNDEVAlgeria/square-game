# Waiter Images

Place your waiter photos in this directory.

## Required Files

1. **waiter-1.jpg** - First waiter photo (the first image you sent)
2. **waiter-2.jpg** - Second waiter photo (the second image you sent)

## Image Guidelines

- Recommended size: 300x400 pixels or similar portrait ratio
- Format: JPG or PNG
- The images will be displayed in a rounded rectangle frame in the game

## Current Setup

The game is configured to look for images at:
- `/waiters/waiter-1.jpg`
- `/waiters/waiter-2.jpg`

Simply rename your photos and place them in this folder.
